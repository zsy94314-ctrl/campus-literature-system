# 系统测试用例文档

## 1 测试说明

本测试用例用于验证《校园学术文献智能检索与综述生成系统》的编译构建、用户端、管理员端、backend-ai、智能检索、综述生成、LLM API 管理、权限控制和异常处理。

测试结果列预留给人工验收填写。文献数量以实际数据库为准，若导入 `literature_seed_500_high_quality.sql`，重建索引返回数量通常为 500 或加上已有示例数据后的实际数量。

## 2 测试环境

| 项目 | 说明 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| 数据库 | MySQL 8.x |
| 后端主服务 | Spring Boot 3.2，端口 8080 |
| 智能检索服务 | FastAPI，端口 8000 |
| 前端 | React + Vite，端口 5173 |
| 浏览器 | Chrome / Edge |
| 测试工具 | PowerShell、浏览器、DevTools、curl / Postman、Maven、npm |
| LLM API | 管理员配置的 DeepSeek / OpenAI-compatible API，可为空 |

## 4 缺陷记录与修复说明

| 编号 | 问题 | 原因 | 修复方式 |
|---|---|---|---|
| BUG-001 | 首页分类统计为 0 | 早期统计逻辑未按全部二级分类真实聚合 | 后端新增分类统计逻辑，遍历全部文献按二级分类计数 |
| BUG-002 | 首页分类跳转不生效 | 前端传分类名称，后端需要 `categoryId` | 首页跳转传 `categoryId`，搜索页监听 URL 参数自动检索 |
| BUG-003 | 智能检索跨学科跑偏 | 纯 FAISS 容易受“人工智能”等宽泛词影响 | 增加主题画像、Query Expansion、MySQL 补充召回、`finalScore` 和 `weakPenalty` |
| BUG-004 | 综述生成模板化 | 早期内容更接近摘要拼接 | 增加主题识别、关键词提取、研究方向归纳、问题与趋势生成 |
| BUG-005 | LLM 输出截断 | `finish_reason=length` 或 token 不足 | 检查 `finish_reason`，必要时提高 `max_tokens` 重试，失败则降级 |
| BUG-006 | LLM 参考文献不完整 | 模型可能漏写或截断第六节 | 后端 `ensureReferencesComplete` 强制补全或替换第六节 |
| BUG-007 | 第六节参考文献被误判为截断 | 缺少第六节时直接判截断，补全逻辑无法执行 | 截断检查只看最后一行，前五节完整即可进入参考文献补全 |
| BUG-008 | LLM 产生不存在的引用编号 | 模型可能输出超出范围的 `[数字]` | 后端 `cleanInvalidCitations` 删除非法引用 |

## 5 测试结论填写建议

人工测试完成后，应补充：

- 各测试类别通过数量。
