## 1 引言

### 1.1 项目背景

写作要点：

- 高校师生在课程学习、科研训练和论文写作中需要查阅大量学术文献。
- 传统关键词检索存在语义理解不足、结果相关性不稳定等问题。
- 文献综述撰写通常需要大量阅读和归纳，耗费时间。
- 智能检索与综述生成可以提高学术资料获取和知识整理效率。

### 1.2 项目意义

写作要点：

- 对普通用户：提高文献检索、收藏和综述整理效率。
- 对管理员：实现文献资源维护、分类管理、用户管理和数据统计。
- 对课程项目：体现软件工程需求分析、系统设计、编码实现、测试和维护全过程。
- 对技术实践：融合前后端分离、语义向量检索、FAISS 向量索引和 RAG 思想。

### 1.3 项目目标

写作要点：

- 建立校园学术文献管理与检索平台。
- 支持普通检索、高级检索和智能语义检索。
- 支持相似文献推荐。
- 支持基于相关文献的结构化综述生成。
- 支持管理员对文献、分类、用户和统计数据进行管理。
- 构建高质量多学科模拟文献库。

### 3.2 功能需求分析

可按功能写输入、处理、输出：

#### 用户注册与登录

- 输入：用户名、密码、邮箱等。
- 处理：校验用户信息，生成 JWT。
- 输出：登录状态和用户信息。

#### 文献普通检索

- 输入：关键词、分类、分页参数。
- 处理：数据库模糊查询。
- 输出：文献列表和总数。

#### 文献高级检索

- 输入：标题、作者、期刊、DOI、分类、文献类型、年份范围。
- 处理：多条件组合查询。
- 输出：符合条件的文献结果。

#### 智能语义检索

- 输入：自然语言主题。
- 处理：调用 backend-ai，使用向量相似度检索。
- 输出：语义相关文献和 similarity。

#### 相似文献推荐

- 输入：当前文献 ID。
- 处理：调用 FAISS 相似向量检索。
- 输出：相似文献列表。

#### 综述生成

- 输入：综述主题和选中文献 ID。
- 处理：根据文献标题、摘要、关键词、正文节选生成结构化综述。
- 输出：综述内容和参考来源。

### 3.3 非功能需求分析

性能需求：

- 检索结果分页展示。
- 智能检索返回前 N 条结果。
- 向量索引预先构建，提高响应速度。

安全性需求：

- JWT 身份认证。
- 管理员接口权限控制。
- 普通用户不能执行索引重建等管理操作。

可靠性需求：

- backend-ai 未启动时返回友好错误。
- 推荐失败不影响文献详情主体展示。
- 综述生成参数不足时返回明确提示。

易用性需求：

- 页面布局清晰。
- 普通检索、智能检索区分明显。
- 综述生成流程清楚。

可维护性需求：

- 前后端分离。
- Java 后端与 Python 智能服务解耦。
- 接口统一返回格式。

可扩展性需求：

- 后续可接入真实论文库。
- 可扩展 BM25、Rerank、真实大模型。
- 可扩展 PDF 上传和全文解析。

## 6 核心功能专项设计

### 6.1 文献检索模块设计

写：

- 普通检索基于 MySQL 模糊查询。
- 高级检索支持多字段组合筛选。
- 支持分页、分类、年份、文献类型、排序。

### 6.2 智能语义检索模块设计

写：

- 用户输入自然语言主题。
- Spring Boot 调用 backend-ai。
- backend-ai 将 query 转为 embedding。
- FAISS 检索相似文献。
- 返回 literatureId 和 similarity。
- Spring Boot 回查 MySQL 补全文献信息。

### 6.3 相似文献推荐模块设计

写：

- 详情页加载后调用 `/api/ai/recommend/{id}`。
- backend-ai 根据当前文献向量检索相似文献。
- 排除当前文献。
- 返回相似文献和相似度。

### 6.4 综述生成模块设计

写：

- 用户输入综述主题。
- 系统智能推荐相关文献。
- 用户选择 2～5 篇。
- 后端根据文献内容生成结构化综述。
- 保存综述记录。

### 6.5 智能检索与综述生成联动设计

重点写：

- 智能检索是综述生成的前置能力。
- 综述生成不是从全部文献中盲选，而是从语义相关文献中选择。
- 体现“先检索，再生成”的流程。

### 6.6 RAG 思想在系统中的应用

写：

- RAG = Retrieval-Augmented Generation。
- 本系统不直接凭空生成综述，而是先检索相关文献，再基于选中文献生成综述。
- 检索材料包括标题、摘要、关键词、正文节选。
- 生成结果保留参考来源，提高可追溯性。

### 6.7 AI 辅助功能边界说明

写：

- 本系统智能检索使用语义向量，不等同于真实学术搜索引擎。
- 文献数据为模拟数据。
- 综述生成采用基于文献内容的结构化生成方式。
- 后续可接入真实论文库、大模型 API、Rerank、BM25 等。
